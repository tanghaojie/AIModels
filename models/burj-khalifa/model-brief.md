# 哈利法塔 / Burj Khalifa 建模任务书

依据 [CS-AM-1](../../docs/modeling-requirements.md)，修订 2026-10-17。由逐建筑任务书模板填写，制作日期 2026-10-20。

## 1. 项目与范围

- ID `burj-khalifa`，v1.0.0，Dubai, UAE，2010 年建成。Blender 5.2.1 LTS。
- 交付：精细塔体、半径 2000 米街区、静态 GLB、飞入拼装 GLB、爆炸 GLB、可编辑 `.blend`、脚本、材质/参考/验收证据、GitHub 与 Vercel 生产发布。
- 视觉重点：三翼 Y 形平面、逐翼螺旋退台、弧形末端、银色横向饰带与竖框、机电层、露台、钢结构冠部/尖塔、入口与场地；周边 Dubai Fountain 湖面、Dubai Mall、道路与真实邻楼轮廓。
- 画幅：静帧 1800×1400 起；动画 1280×960，30 fps 源动画。先完成真实渲染检查再记录最终值。无浏览器自动化。

## 2. 资料与精度

- 高度 828 米，SOM 官方项目页；SOM 的 160 层为其项目统计，其他来源层数定义不一致，不以窗行数宣称实际楼层。
- SOM 典型平面/剖面/轴测原图及实景照片保存 `references/originals/`，各自来源、署名、用途、下载摘要见 `references/download-manifest.json`。受版权限制原件仅本机保留；Git 包含可复现下载脚本和来源。CTBUH 历史 PDF 下载失败，没有作为已读依据。
- 塔体轮廓/退台/冠部以 SOM 建筑师图纸和建成摄影交叉参考。宽深、逐层高度、板厚、内部结构为可视化重建估算；不称实测或施工 BIM。
- 街区原始数据：OpenStreetMap Overpass 快照，半径 2000 米裁切。保留源数据与 ODbL 署名。缺失建筑高度按已知楼层/类型估算，明确统计，立面和屋顶细部为示意。Dubai Mall 主体因关系接口未返回，按 SOM 鸟瞰图手动补绘近似体量，单独标注约 40–60 米平面误差及 28 米估算高度；未复制后期扩建，不冒充精确 OSM 轮廓。

## 3. 定位

- 近似 WGS84 锚点 [55.274375,25.197197]，将通过 OSM 塔基轮廓核对。真实椭球高未知，GLB 省略。
- 唯一固定 `GEO_ROOT` 位于塔基地面中心。Blender +X 北/+Y 西/+Z 上；glTF +X 北/+Y 上/+Z 东，米制 scale=1。
- 发布使用 `terrain: ellipsoid`，height=0 仅演示，notice 明示。主体和街区同锚点。

## 4. 材质与 UV

- PBR 实接 Principled：非金属镀膜玻璃（不透明、有窗灯贴图和室内暗区）、裸铝/钢、石材、混凝土、沥青、植被、水面。
- 固定布局原创建筑表面纹理，米制 UV；独立 Base Color / roughness / emissive。玻璃金属度 0，裸金属 1；不会以颜色视图代替实际材质。
- 窗灯静态冷暖/暗区跟随所属幕墙件；运行时昼夜交由消费端唯一 clock，不加计时器。
- 细节以几何横向楼层带、竖框、露台栏杆、机电百叶、屋顶设备与入口为主。不得数万个窗格独立动画。

## 5. 光照与预览

- 独立 `BK_PREVIEW_ONLY`：太阳、面积补光、天空、相机、远景地平面；全部排除 GLB。
- AgX；保存同构图日光/日落/蓝调/夜间，补入口/侧后/幕墙/俯瞰/街区及各动画阶段。具体能量/采样/相机参数随工程保存并写入验证记录。
- 预览是 Blender 证据；Cyber-Sight/GPU/浏览器真实效果仍由维护者人工验收。

## 6. 分件与动画

- 按底座、核心段、楼层组、三翼幕墙/露台、机电层、冠部、入口拆分约 300–500 个逻辑组，玻璃/框/窗灯同枢轴。
- 固定 `GEO_ROOT`，各 PART 直属根节点；枢轴及装配 TRS 见 `parts.json`，统一 gltf-local-y-up。
- 36 秒飞入：0–1 秒空场，1–8 秒核心，4–18 秒楼板，9–24 秒幕墙/冠部/入口；所有件从空中向下飞入，在离地 120 米组装，25–27 秒高空保持，27–32 秒整体平稳降至地面，32–36 秒成品保持。具体依赖随部件表记录。
- 14 秒爆炸：0–1.5 秒成品保持，1.5–10 秒分层/分翼有序展开，10–14 秒末态保持。
- 每个文件一个片段；默认节点保持成品装配姿态。GLB 用核心 TRS、共同 t=0、30 fps 采样，不把动画当精细度。

## 7. 预算、复现与发布

- 塔体实际 885,354 三角形，276 组构件；超过规范建议预算，保留弧形幕墙、实体横带和分解内侧，作为高精度例外记录。街区 415,631 三角形，独立 3D Tiles 附件。不承诺未经实测的目标设备 FPS。
- 源工程、外部纹理、配置、脚本相对引用；脚本只替换本项目场景/命名集合，不清空别的场景。
- 主静态加 assembly/explode `modes`；使用仓库 publish 工具，GLB 经 Khronos Validator 后发布。线上核对 READY/提交/HTTP/MIME/CORS/完整 SHA-256。
